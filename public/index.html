MAKE IT YOURS

Connect your channels

Automatic monitoring uses Google's free, quota-limited YouTube Data and Analytics APIs. Connect each Google / Brand Account identity separately.

  1. Open Google Cloud Console, create a project, and enable YouTube Data API v3 and YouTube Analytics API.
  2. Configure OAuth consent. While in Testing, add your Google account under Test users.
  3. Create an OAuth Web application client. Add this exact redirect URI: http://localhost:3010/oauth/callback

Google test-mode refresh tokens normally expire after 7 days. Reconnect when asked. Monitoring runs hourly while this server is running and the computer is awake. To revoke access, remove the app in your Google Account permissions.

Import from YouTube Studio

In Studio → Analytics → Advanced mode, choose the date range, set the table to Content / Video, and export Table data (.csv). Use English column headings. You can import reach metrics such as impressions and CTR too.

Select the exact dates used in the export below. Imports are a manual snapshot. A later API sync replaces the base video report for that same channel and date range. Keep reach exports as separate reference snapshots when needed.
